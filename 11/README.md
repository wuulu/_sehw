## 一、網站連結

開啟網址即可使用，不需要安裝任何東西：

**<https://wuulu-hw9.yulu96413.workers.dev/>**

這個網址是部署在 Cloudflare Workers 上的靜態網站，手機與電腦都能直接開啟。網站沒有登入機制，也不需要伺服器處理資料，所有的名單與抽籤紀錄都只保存在你目前使用的瀏覽器中。

## 二、網站簡介

「抽籤所」是一個為班級活動、聚餐抽獎、課堂點名等場合設計的線上抽籤工具。製作的出發點是：市面上許多抽籤網站不是充斥廣告，就是需要註冊帳號，而且往往一次只能抽一位。因此這個專案的目標是做一個**乾淨、快速、公平、免登入**的抽籤頁面。

網站採「純前端」設計：沒有後端程式、沒有資料庫。HTML 負責頁面結構，CSS 負責視覺與動畫，JavaScript 負責全部邏輯，資料則存放在瀏覽器的 `localStorage`。這樣的好處是部署簡單、反應速度快，而且使用者的名單不會上傳到任何地方。

## 三、網站的功能

1. **多人名單輸入**：每一行輸入一位名字，也可以用逗號、頓號、分號分隔；重複的名字會自動合併，前後多餘空白也會清除。
2. **一次抽出多位**：可設定每次抽出 1 到 50 位得主，並用加減按鈕或直接輸入數字調整。
3. **不重複中獎**：預設開啟「不重複」，抽過的人不會再進入籤筒；也可手動切換成允許重複中獎。
4. **抽籤動畫**：名字快速輪播、得主卡片依序進場，中獎時還有彩帶（confetti）特效，氣氛感十足。
5. **公平抽取**：使用瀏覽器內建的 `crypto.getRandomValues` 產生亂數，搭配 Fisher-Yates 洗牌演算法，並用拒絕取樣避免取餘數造成的偏差。
6. **歷史紀錄**：保留最近 50 次結果，標示抽獎時間、得主與當時籤筒人數。
7. **撤回與清除**：可以撤回上一次抽籤（例如抽錯時），也可以一次清除所有紀錄（需再次確認）。
8. **CSV 匯出**：將紀錄匯出成 Excel 可直接開啟的 UTF-8 CSV 檔，欄位包含時間、中獎者、抽出人數與籤筒人數。
9. **自動儲存**：名單、設定與紀錄即時存入瀏覽器，重新整理或隔天再開啟都還在。
10. **響應式與無障礙**：手機、平板、桌機都能使用；支援鍵盤快捷鍵 `Ctrl + Enter`（macOS 為 `Cmd + Enter`），並對「減少動態效果」設定與螢幕閱讀器做處理。

## 四、網站如何使用

1. **開啟網站**：連上上面的網址，畫面會先載入 12 位示範名單，可直接體驗。
2. **輸入名單**：在左側「籤筒」的文字框中，一行輸入一個名字；想快速開始可按「載入示範名單」，想重來可按「清空名單」。
3. **設定抽出人數**：在中間下方用「− / ＋」調整，或直接輸入 1–50 的數字。若人數超過可抽人數，系統會自動修正並提示。
4. **決定是否重複**：預設「允許重複中獎」是關閉的（抽過的人不會再中）；若活動需要每個人都可能再次被抽到，可打開此開關。
5. **開始抽籤**：按「開始抽籤」或 `Ctrl + Enter`。畫面會先快速輪播名字，約 1.5–2 秒後公布得主，並灑下彩帶。
6. **查看結果**：得主卡片會顯示在抽籤舞台，左側的「可抽人數 / 已中獎」也會同步更新。
7. **管理紀錄**：在下方「抽籤紀錄」區可「撤回上次」、「匯出 CSV」或「清除紀錄」。清除與清空名單都會先跳出確認視窗，避免誤觸。
8. **資料保存**：以上操作都會自動存到本機瀏覽器，不需要按儲存；但換裝置或清除瀏覽器資料後就不會同步。

## 五、網站如何製作

### 5.1 整體架構

網站由四個前端檔案與兩個設定檔組成，沒有任何 npm 外部套件：

```
瀏覽器
  │  載入靜態檔案
  ▼
Cloudflare Workers（assets.directory = ./public）
  │
  ├─ index.html   頁面結構
  ├─ style.css    樣式、動畫、響應式
  └─ app.js       抽籤邏輯、儲存、紀錄、彩帶
                    │ 讀寫
                    ▼
              localStorage（lucky-draw-v1）
```

流程是：使用者開啟網址 → Cloudflare 回傳 `public/` 內的靜態檔案 → 瀏覽器執行 `app.js` → 所有狀態讀寫都在本機完成，完全不經過伺服器。

### 5.2 檔案職責

| 檔案 | 職責 |
| --- | --- |
| `public/index.html` | 頁面骨架：導覽列、籤筒、抽籤舞台、控制項、紀錄區與頁尾；包含 inline SVG 圖示與 Accessibility 標記。 |
| `public/style.css` | 深色主題（CSS 變數）、漸層背景、光球飄移、卡片進場、搖晃、彩帶畫布與兩個響應式斷點（940px / 620px）。 |
| `public/app.js` | 核心邏輯：名單解析、亂數與洗牌、狀態管理、抽籤流程、歷史紀錄、CSV 匯出與 Canvas 彩帶。 |
| `server.js` | 本機預覽用的極簡靜態伺服器，只用 Node.js 內建 `http / fs / path`，並阻擋路徑穿越攻擊。 |
| `wrangler.jsonc` | Cloudflare Workers 設定：名稱 `lucky-draw`、靜態資源目錄 `./public`。 |
| `package.json` | `start`（本機預覽）、`check`（語法檢查）、`deploy`（Wrangler 部署）三個指令。 |

### 5.3 核心實作細節

- **名單解析**：用正則 `[\n\r,，、;；|]+` 切割字串，再透過 `Set` 去重並修剪空白，所以中英文標點混用也能正確分開。
- **公平亂數**：`randomInt(max)` 優先使用 Web Crypto 的 `getRandomValues`，並以 `limit = floor(0xffffffff / max) * max` 拒絕超出範圍的樣本，避免單純取餘數造成的機率偏差；若環境不支援才退回 `Math.random()`。
- **抽籤演算法**：`sample()` 先複製名單，再由後往前做 Fisher-Yates 洗牌，最後取前 N 個，因此每位參加者中獎機率相同，且一次抽多位也不可能重複。
- **不重複機制**：從歷史紀錄建立「已中獎集合」，再用 `filter` 產生可抽名單；打開「允許重複」時直接回傳完整名單即可切換行為。
- **狀態管理**：`loadState()` 會驗證並清洗讀到的資料（型別檢查、去重、限制筆數），`persist()` 用 try/catch 包住寫入，即使無痕模式無法使用儲存空間，網站仍能在記憶體中正常運作。
- **動畫與體驗**：抽籤時先禁用所有控制項避免連點，名字每 68 毫秒更換一次；若使用者系統設定「減少動態效果」，動畫時間會縮短、彩帶直接跳過，兼顧效能與無障礙。
- **CSV 匯出**：手動組裝 CSV 字串（引號跳脫、逗號分隔、`\r\n` 換行），在開頭加入 UTF-8 BOM（`\ufeff`），再用 `Blob` 與 `URL.createObjectURL` 觸發下載，Excel 開啟不會亂碼。

### 5.4 部署方式

專案提供三種部署途徑：

1. **連結 Git 儲存庫（推薦）**：在 Cloudflare Dashboard 選擇 Pages → Connect to Git，Root directory 設為 `09`、Build command 留空、Build output directory 設為 `public`，之後每次 push 都會自動重新部署。
2. **直接上傳資料夾**：在 Cloudflare Pages 選擇 Upload assets，把 `public/` 內的檔案上傳，注意 `index.html` 必須在最上層。
3. **Wrangler 部署為 Worker**：`wrangler.jsonc` 已設定好靜態資源目錄，執行 `npx wrangler login` 後再 `npx wrangler deploy`，即可取得 `*.workers.dev` 網址（本網站即採此方式）。

## 七、本機執行與檢查

需要 Node.js（僅用於本機預覽，沒有外部套件）：

```bash
npm start
```

開啟 <http://localhost:3000>。若要更換連接埠：

```bash
$env:PORT=8080; npm start   # Windows PowerShell
PORT=8080 npm start         # macOS / Linux
```

調整程式後可執行語法檢查：

```bash
npm run check
```
