# wuulu 記帳

> 把每一塊錢，記成未來的樣子。

一個以「剛剛好的富足」為起點的個人記帳工具。純前端實作，所有資料只儲存在瀏覽器的 `localStorage`，不上傳、不追蹤。

## 功能

- **總覽**：總資產、本月收入／支出、儲蓄率、近六個月收支趨勢、支出分類圓餅圖、預算進度與最近交易
- **交易**：新增、編輯、刪除收支紀錄，支援關鍵字搜尋、類型／分類／月份篩選，匯出 CSV
- **預算**：依分類設定每月上限，即時顯示使用比例、剩餘與超支狀態
- **分析**：收支長條圖、支出分類佔比與排行、各帳戶資產分佈
- **帳戶**：管理銀行、現金、信用卡、電子錢包，自動計算目前餘額
- **設定**：淺色／深色主題、匯出／匯入 JSON 備份、載入範例資料、清除資料
- 首次開啟自動載入示範帳目，方便快速體驗

## 快速開始

需要 Node.js（僅用於內建的靜態伺服器，無外部相依套件）。

```bash
npm start
```

開啟 <http://localhost:3000> 即可使用。若要改用其他連接埠：

```bash
# Windows PowerShell
$env:PORT=8080; npm start

# macOS / Linux
PORT=8080 npm start
```

也可以直接用瀏覽器開啟 `index.html`，但透過本機伺服器執行較能確保 `localStorage` 正常運作。

## 資料儲存

所有資料保存在瀏覽器 `localStorage` 的 `xiaoman-ledger-v1` 鍵值中，結構如下：

```json
{
  "version": 1,
  "transactions": [],
  "accounts": [],
  "budgets": {},
  "settings": { "theme": "light" },
  "waitlist": []
}
```

- 點選「設定 → 匯出 JSON」可下載完整備份，並在其他裝置匯入還原。
- 匯入備份會**取代**目前所有資料。
- 清除瀏覽器資料或更換瀏覽器會遺失紀錄，建議定期備份。

## 開發

```bash
npm run check   # 使用 node --check 檢查 JS 語法
```

本專案不使用建置工具、框架或外部相依套件，修改檔案後重新整理瀏覽器即可。

### 主要進入點

- `app.js` 的 `init()`（`app.js:1537`）負責初始化導覽、主題、事件與畫面渲染
- `render()`（`app.js:529`）依 `state.view` 切換各頁面
- 資料讀寫分別在 `loadData()`（`app.js:286`）與 `persistData()`（`app.js:304`）

## 注意事項

- 「小滿 Pro」方案與等候名單為展示用途，不會實際收費或送出資料。
- 匯出 CSV 會加上 UTF-8 BOM，方便以 Excel 開啟中文內容。
